Maintenance Short DPR – NG-2000-1
==================================
Offline iPhone/iPad PWA for New Generation Rig NG-2000-1.

Features:
- New DPR with automatic DPR number
- Multiple DPRs saved offline using IndexedDB
- DPR History with Open and Delete
- Critical equipment and HVAC status: RUN / S/B / U/M
- POL and Grease accept text + numbers
- Equipment-specific maintenance/issues
- Generic jobs
- Inventory/requirements
- Crew details
- Full DPR text sharing
- Complete DPR sharing using iPhone Share sheet; select WhatsApp
- Service worker cache: maintenance-dpr-final-v7

Deployment:
Upload index.html, service-worker.js, manifest.json and icons to the GitHub Pages repository.
Open the HTTPS Pages URL once online in Safari, then Add to Home Screen.
Do not use Private Browsing for offline storage.

Rig-specific build: NG-2000-1

Maintenance equipment name is a free-text field; users enter the equipment name manually.
